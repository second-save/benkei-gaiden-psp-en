# Benkei Gaiden (PSP PC Engine Archives, NPJJ30035) — Project Glossary

Inherits all canonical game terms and rulings from `../benkei-gaiden-pce/glossary.md` (`Kijaku`, `Benkei`, `Sayaka`, `Saburo`, `Hogen`, `O-Koto`, `Yoichi`, `Kichijiro`, `Sen`, `Jutsu`, `Rinsho-ji`, etc.).

## Core Rulings (`docs/decisions.md`)
- **D2 Honorifics:** Drop all Japanese honorifics (`-san`, `-sama`, `-dono`, `-chan`, `-kun`).
- **D3 Romanization:** Standard Hepburn without macrons (`Hogen`, `Kijaku`, `Yoshitsune`, `Yoritomo`, `Kiyomori`, `sen`).
- **D4 Credits:** Translate all staff/credits in-game and in manual/XMB into English.
- **D5 No Abbreviations:** Write full terms cleanly (`Manual`, `Screen Size`, `Autosave`, `Save (Suspend)`, `Load (Resume)`).
- **D6 Graphics Text:** Translate all tile-drawn game graphics, XMB assets (`PARAM.SFO`, `PIC0.PNG`, `ICON0.PNG`), GIM screens (`chyuikanki_PSP.GIM`, `HUDSON.GIM`, `WALL.GIM` if text present), and the 18-page digital manual (`psp_001.png`..`psp_018.png`).
